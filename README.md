# CCode

**Локальный ИИ-ассистент для кодинга на Android.**

CCode помогает создавать исходные файлы, Godot-проекты и многофайловые приложения прямо на телефоне. Проект использует локальные модели Code 1.0 и Code 1.0 Lite.

## Возможности

- локальная генерация кода;
- поддержка Python и Godot 4.x / GDScript 2.0;
- создание отдельных файлов и ZIP-проектов;
- импорт и анализ скриптов, ZIP и APK;
- веб-поиск документации с источниками;
- панель активности с этапами работы ИИ;
- экспорт чатов в `.ccode`;
- тёмный интерфейс, история чатов и статистика.
